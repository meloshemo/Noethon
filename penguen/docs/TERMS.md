## 1. Acceptance

Opening the game means you accept these terms. If you do not, closing the tab is
enough. There is no account or subscription to cancel.

## 2. Price

The game is **free.** The in-game shop runs entirely on fictional currency
(fish), and fish are earned only by playing. There are no real-money purchases,
no ads and no subscriptions. If that changes, this text changes and you will see
the date here.

## 3. No account

You are not signing up. The name you type and the id you are given
(`PNG-XXXXX`) live only on your own device. Which means:

- **Your progress is tied to this device.** Clear your browser data and the save
  is gone.
- **Backing it up is on you.** *Settings → Legal and data → Export my save*
  downloads it as JSON.
- There is no automatic transfer from one device to another.

The game has no violence, no frightening imagery, no gambling and no chat. It
does have fast motion and shake effects. If those bother you, **Settings →
